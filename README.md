## 📱 About
Food Search App is a React Native (Expo) application that allows users to search food products using the OpenFoodFacts API by name or barcode.

## ✨ Features
- Search food by name
- Search food by barcode
- Display product images
- Show brand information
- List multiple results

## 🛠️ Tech Stack
React Native • Expo • JavaScript • OpenFoodFacts API • React Hooks

## 🚀 Run Project
```bash
git clone https://github.com/TsionY07/food-search-app.git
cd food-search-app
npm install
